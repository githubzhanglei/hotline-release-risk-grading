# Synthetic Sample Data Schema

File: `data_sample/synthetic_hotline_sample.csv`

The file contains 400 fully synthetic rows and 22 columns. Values are generated by `scripts/make_synthetic_sample.py` from a fixed seed. The sample preserves only the field structure needed by the metric scripts.

| Column | Meaning in the demo sample | Synthetic-value rule |
|---|---|---|
| `sample_id` | Row identifier for the toy sample | Sequential integer |
| `ticket_date` | Ticket date | Synthetic dates over a 74-day window |
| `person_id` | Pseudonymous contributor key | Fake `Pxxxxx` strings or blank |
| `区县地址` | Administrative district | Fake districts: `甲区`, `乙区`, `丙区` |
| `街道地址` | Administrative street | Fake street labels under fake districts |
| `mapped_l1_name` | Coarse topic label | Fake topic classes |
| `mapped_l2_name` | Fine topic label | Fake topic subclasses |
| `是否回访` | Follow-up flag | Synthetic yes/no |
| `问题是否解决` | Resolution flag | Synthetic yes/no |
| `是否热点` | Hot-topic flag | Synthetic yes/no |
| `承办单位` | Handling unit | Fake unit labels |
| `text_subject_id` | Text-derived subject key | Fake `TSxxxxx` strings or blank |
| `text_subject_type` | Text-derived subject type | Fake type labels |
| `text_place_id` | Text-derived place key | Fake `TPxxxxx` strings or blank |
| `text_place_type` | Text-derived place type | Fake type labels |
| `address_id` | Stable address key | Fake `Axxxxx` strings or blank |
| `has_address_id` | Address-key presence flag | 0/1 derived from `address_id` |
| `has_text_place_id` | Text-place-key presence flag | 0/1 derived from `text_place_id` |
| `has_text_subject_id` | Text-subject-key presence flag | 0/1 derived from `text_subject_id` |
| `sanitized_text` | Demonstration text field | Repeated synthetic sentence with fake topic and sample number |
| `person_total_complaints` | Synthetic recurrence count by `person_id` | Derived from the toy sample |
| `address_total_complaints` | Synthetic recurrence count by `address_id` | Derived from the toy sample |

The synthetic sample uses fake administrative names, fake person keys, fake address keys, fake place keys, and fake complaint text. It does not contain real municipal-service records.
